### 2. ⚡ Zoho CRM 4-Layer Quotation Automation Engine
- **Problem**: 30+ minute manual quotation drafting riddled with arithmetic and specification errors.
- **Solution**: End-to-end 4-layer automation pipeline:

  - **Layer 2 (Deluge Functions)**: Dynamic roofing formulas, tax slabs & vendor margin calculations.
  - **Layer 3 (Client Script JS)**: Instant UI color-to-image preview syncing assets via Cloudinary.
  - **Layer 4 (Zoho Writer API)**: Auto-compiles branded PDFs and links directly to CRM deal records.
- **Impact**: Slashed quote generation time to **< 1 minute** with **0% calculation errors**.
